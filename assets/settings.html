    Repair

    Reinstall the packages Every package from Arch Linux ARM installs again the next time Local Desktop starts, for a desktop or a program that lost or broke some of its files. Your files and settings stay. It takes a few minutes, and downloads only what isn't in the package cache. Set for the next start.
    Reset the settings Everything on this page back to its default, except the desktop and the user, and the commands in the file go. The old file stays next to it, as localdesktop.toml.bak.

    Backup

    Back up the Linux system Into a file you pick: Downloads, an SD card, a USB stick, Drive. A running desktop logs out first, so that its programs can save, and starts again when you go back to it.
    Restore a backup It takes this Linux system's place the next time Local Desktop starts; until then, nothing changes. Backups from any Local Desktop app work, and so does a tar of a Linux system.
